# Setup (read once, then you can delete this file)

1. On GitHub create a **public** repository named exactly `Anima-Das` (same as your username). Tick "Add a README".
2. Upload everything from this folder (README.md, assets/, .github/) to the repository root.
3. Repo Settings > Actions > General > Workflow permissions > **Read and write permissions**.
4. Actions tab > "GitHub-Profile-3D-Contrib" > **Run workflow**. It creates the `profile-3d-contrib/` folder
   that the 3D graph section of the README uses. Until it runs once, that image shows as broken.
5. Optional: delete this SETUP.md.
